# 📂 ComparadorF

El archivo **`lector_imagenes.py`** compara dos archivos de texto (`.txt`) y muestra sus diferencias de manera detallada.  
El programa analiza línea por línea y, en caso de detectar diferencias, indica:

- En qué línea ocurren.
- En qué posiciones de caracteres se encuentran las diferencias.
- Una salida tanto en consola como en el archivo **`output.txt`** generado automáticamente.

---

## Requisitos

- Python 3.x instalado en tu sistema.
- Archivos de texto con el contenido a comparar.

---

## Uso

1. Coloca en la **misma carpeta** el archivo `lector_imagenes.py` junto con los dos archivos de texto que quieras comparar.
   - Los nombres por defecto son:
     - `foto.txt`
     - `foto2.txt`

2. Ejecuta el programa desde la terminal con:

   ```bash
   python3 lector_imagenes.py
